# Champs électromagnétiques <small>`SP301P`</small>

Électrostatique (force, champ, potentiel, énergie, théorème de Gauss) puis magnétostatique
(Biot et Savart, théorème d'Ampère). Le fil rouge : **lire les symétries d'une distribution de
charges ou de courants pour choisir la bonne méthode**, intégration directe ou théorème.
