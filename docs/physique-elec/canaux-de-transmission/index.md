# Canaux de transmission <small>`TE403P`</small>

Comment un signal voyage sur un support physique : **lignes de transmission**
(échelon et réflexions, régime sinusoïdal, abaque de Smith, adaptation
d'impédance) puis **fibres optiques**. Le fil rouge : savoir quand une ligne
réfléchit le signal, et comment l'empêcher.
