# Travaux pratiques

Les TP se font sur **Multisim** (fichiers `.ms14`) avec la famille de portes
`74HC_4V`. Chaque TP a deux parties : les **fichiers circuits**, à télécharger
et ouvrir dans Multisim, et le **PDF** du TP rempli.

| TP | Sujet | Contenu |
|----|-------|---------|
| [TP 1 — Bascules](tp-1-bascules.md) | Bascules RS et D | Table de vérité, chronogrammes, circuit intégré 7474, limite en fréquence |
| [TP 2 — Registres](tp-2-registres.md) | Registres | Registre 3 bits à chargement S/P, registre bidirectionnel (74HC174), registre intégré 74HC164 |

!!! info "TP 3"
    Le TP 3 (compteurs) sera ajouté après la séance.

!!! tip "Ouvrir un fichier circuit"
    Il faut **Multisim 14** (ou plus récent). Un clic sur le lien télécharge
    le fichier ; ouvre-le ensuite avec *File → Open*.
