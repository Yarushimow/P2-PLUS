# Propagation électromagnétique <small>`SP401P`</small>

Les **outils d'analyse vectorielle** (gradient, divergence, rotationnel, laplacien),
les **équations de Maxwell** et l'induction, la **propagation des ondes** dans le vide
(équation de d'Alembert, ondes planes sinusoïdales) et l'**énergie** qu'elles
transportent (vecteur de Poynting, intensité, photons).
