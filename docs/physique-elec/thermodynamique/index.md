# Thermodynamique <small>`SP402P`</small>

Énergie, chaleur et travail : les **bases** (systèmes, gaz parfait), le
**premier principe** (conservation de l'énergie), le **second principe**
(entropie, irréversibilité) et leur application aux **machines thermiques**
(moteurs, réfrigérateurs, pompes à chaleur).
