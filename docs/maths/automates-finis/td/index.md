# Travaux dirigés

Le cahier d'exercices du module (21 exercices et une feuille bonus). Chaque page a deux onglets :
**Version simplifiée** (corrections) et **Version papier** (les énoncés). Les automates sont donnés
par leur **table de transitions** : E = état initial, S = état terminal (de sortie), P = état poubelle,
« – » = pas de transition. Toutes les réponses ont été **vérifiées par programme** (mots reconnus,
déterminisation, minimisation).
