# :material-dice-multiple: Simulateur d'exercices

Des exercices **générés au hasard** sur les chapitres 1 à 3 : **39 types, un par formule du cours**.
Chaque clic sur « Nouvel exercice » change les valeurs. Réponds, vérifie, et ouvre l'**indice**
ou la **correction détaillée** si tu bloques. Le score est gardé dans ce navigateur.

<div id="simulateur-proba"></div>

??? info "Les 39 types d'exercices"
    | Chapitre | Exercices |
    |----------|-----------|
    | 1. Espace probabilisé | De Morgan (traduire « ni… ni », « pas les deux », « exactement un »…), Venn à 3 évènements et distributivité, réunion / intersection / complémentaire, bornes (inclusion, Boole, Bonferroni), Poincaré à 3 ensembles, effectifs → probabilités, deux dés, « au moins un » sur $n$ essais, tirages ordonnés sans répétition (anniversaires), tirages simultanés $\binom{n}{k}$, QCM de cours |
    | 2. Conditionnement | arbre pondéré à compléter, probabilités composées (3 tirages), Bayes (dépistage, deux urnes), probabilités totales (trois machines), urne sans remise, tableau de contingence, indépendance, indépendance et complémentaires, circuits (évènements indépendants), « $E$ avant $F$ » et série géométrique, suite récurrente $p_{n+1} = a p_n + b$, QCM de cours |
    | 3. Variables discrètes | loi + $E$ + $V$, trouver la constante d'une loi, fonction de répartition, loi de $g(X)$ et transfert, somme de deux variables indépendantes, loi conjointe + covariance, écart-type et corrélation $\rho$, règles de calcul sur $E$, $V$, $\mathrm{Cov}$, indicatrices, moyenne empirique, uniforme, binomiale, Poisson, géométrique / binomiale négative, QCM de cours |

!!! tip "Pour réviser le CE"
    1. Coche **Parcours complet** : tu passes une fois par chaque type, dans le désordre (barre de progression).
    2. Dans le menu **Formule**, chaque type est marqué ✓ (réussi), ✗ (à revoir) ou ○ (pas encore fait).
    3. Choisis **À retravailler** pour ne tirer que les types ratés ou pas encore faits.
    4. Relis la [fiche CE](../fiches/fiche-ce-chapitres-1-3.md) et le [formulaire](../fiches/formulaire-ce.md) avant de recommencer.
