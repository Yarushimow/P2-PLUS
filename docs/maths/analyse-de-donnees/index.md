# Analyse de données <small>`SM403P`</small>

Décrire des données (**statistique descriptive**, régression), estimer les paramètres
d'une population (**intervalles de pari et de confiance**), décider avec un risque
maîtrisé (**tests d'hypothèse**, $\chi^2$) et résumer un grand tableau de données
(**analyse en composantes principales**).
