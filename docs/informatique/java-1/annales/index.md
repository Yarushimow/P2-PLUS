# Annales

=== "Version simplifiée"

    Sujets de DE des trois dernières années, avec leurs corrections, et le
    sujet de rattrapage 2023-2024. Le DE dure 2 h et compte pour 60 %.

    | Année | Sujet | Correction |
    |---|---|---|
    | 2025-2026 | DE | oui |
    | 2024-2025 | DE | oui |
    | 2023-2024 | DE et rattrapage | oui |

    !!! methode "Ce qui revient à chaque fois"
        - **Lecture de code** : prévoir l'affichage (constructeurs enchaînés,
          références partagées, `==` vs `equals`, liaison dynamique).
        - **Trouver les erreurs** de compilation (constructeur manquant, `private`,
          méthode abstraite non implémentée, downcast).
        - **Écrire des classes** : attributs privés, constructeurs (dont copie),
          getters/setters, `toString`, `equals`, puis une hiérarchie avec classe
          abstraite et/ou interface et un tableau polymorphe.

    Conseil : faire le sujet en temps limité **sur papier**, puis comparer à la correction.
