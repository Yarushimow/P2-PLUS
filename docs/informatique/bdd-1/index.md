# Bases de données 1 <small>`TI404P`</small>

Concevoir puis exploiter une base de données relationnelle avec la méthode
**Merise** : analyse des besoins, **MCD** (entité/association) et normalisation,
**MLD** (modèle relationnel), **MPD** en SQL, puis interrogation en **algèbre
relationnelle** et en **SQL** (MySQL).
