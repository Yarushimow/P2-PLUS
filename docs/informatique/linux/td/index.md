# TP corrigés

Le module n'a pas de TD : tout se fait en cours-TP. Chaque page reprend les
exercices d'un TP avec la réponse dépliable (« Correction »). Les énoncés complets
sont sur le [site du cours](https://yvanguifo.github.io/introduction-linux-fr/).

| Page | Exercices |
|------|-----------|
| [TP1 corrigé](tp1-corrige.md) | Raccourcis, arborescence, `mkdir` / `mv` / `cp` / `rm`, aide, jokers |
| [TP2 corrigé](tp2-corrige.md) | `/etc/passwd`, lecture des droits, `chmod`, droits sur dossiers, `PATH`, « on lâche le clavier », `umask` |
| [TP3 corrigé](tp3-corrige.md) | Variables, `\` `'` `"`, accolades, `$(…)`, `gcc`, compilation séparée, `read` / `write` / `dup2` / `dup` |
| [TP4 corrigé](tp4-corrige.md) | Redirections, tubes, `sleep` / `compteur`, `kill`, `signal`, `fork`, mini-shell |
| [TP4+ corrigé](tp4-filtres-corrige.md) | Filtres, `.h` les plus légers, `grep -r` / `-l`, `sed`, `awk`, script `/etc/passwd` |
| [**Annale CC1 2023**](annale-cc1-2023.md) | Le QCM de 20 questions, réponses expliquées |

!!! tip "Format de l'examen"
    QCM sur Moodle. Les énoncés de TP signalent les exercices « représentatifs d'un
    item de QCM du DE » : TP1 ex. 4 et 7, TP2 ex. 5 et 7, TP3 ex. 7, plus la
    programmation système ⭐ des TP3 et TP4.
