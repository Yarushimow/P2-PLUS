# Introduction à Linux <small>`TI307P`</small>

GNU/Linux en ligne de commande sur Debian : le shell Bash, le système de fichiers
et les droits, les variables et le quoting, la compilation C, les redirections, les
processus et les signaux, jusqu'à la programmation système (`fork`, `exec`, `dup2`).
